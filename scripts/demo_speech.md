# 现场演示口播脚本 · 剧本记忆层

> 目标观众:剧作者(非技术)
> 总时长:~7 分钟
> 需要的屏幕:**左/上 = 终端**、**右/下 = Neo4j Browser**(http://localhost:7474)
> 故事梗概(3 场种子剧本):
> - 第1集第1场:李静在咖啡馆告诉张伟,**她是被领养的**
> - 第1集第2场:张伟独自坐在咖啡馆反复咀嚼这件事,**决定帮她找亲生父母**
> - 第2集第1场:生母**周雅静**站在窗前望街,**不知道**30年前送出的女儿正在寻找她

---

## 演出前 T-10 分钟(预灌 + 排练兜底)

```bash
# 1. Neo4j 起着
docker compose up -d

# 2. 冻结记忆图(一次性,慢 60-90s,现场不再跑)
python scripts/populate_graph.py

# 3. Neo4j Browser 肉眼验一下节点都是中文
#    浏览器打开 http://localhost:7474
#    跑: MATCH (n) WHERE n.group_id='test_project' RETURN n LIMIT 50

# 4. 预录所有要演的命令 → 写进 demo_cache.json
#    (每条命令都跑一次 --record, 这样现场如果 OpenRouter 抽风可以 --replay)
python scripts/demo.py ask --record --no-memory --character 张伟 --at 1,2 \
  --q "请详细列出张伟在第1集第2场时刻所知道的所有事实,一条一条列出来。"
python scripts/demo.py ask --record --memory    --character 张伟 --at 1,2 \
  --q "请详细列出张伟在第1集第2场时刻所知道的所有事实,一条一条列出来。"
python scripts/demo.py who-all --record --at 1,2
python scripts/demo.py continue --record --no-memory --at 2,1
python scripts/demo.py continue --record --memory    --at 2,1

# 5. 预热网络 + 缓存
python scripts/demo.py ask --memory --character 张伟 --at 1,2 --q "预热"
```

> **演出时全部加 `--replay`**,稳如老狗,效果和 live 一样。

### Neo4j Browser 预置 query(演出前粘到 favorites 里)

* **全局看图**:
  `MATCH (n) WHERE n.group_id='test_project' RETURN n LIMIT 50`
* **第一幕用 — 张伟的认知边**:
  `MATCH (a:Character {name:'张伟', group_id:'test_project'})-[r]->(b) RETURN a,r,b`
* **第二幕用 — 三人全景**:
  `MATCH (a:Character)-[r]->(b) WHERE a.group_id='test_project' AND a.name IN ['李静','张伟','周雅静'] RETURN a,r,b`

## 开场(1 min) · 设 hook

> 🎙️ "你们写长剧本最大的敌人是什么?"
> *(等一个回答,通常会有人说'前后矛盾' / '人物穿帮')*
>
> "对。我花了几周时间跟 ChatGPT、Claude 合作写剧本,我总结出一句话:"
>
> **"大模型写剧本的问题不是写不好,是**不记得**。"**
>
> "今天我想给你们看一个东西——一个专门给剧作用的**记忆层**——然后用现场对比,让你们决定它有没有用。"
>
> *(屏幕打出 3 场种子剧本的一句话梗概)*

## 🎬 第一幕 · 散文 vs 结构化记忆(3 min)

> 🎙️ "先问一个在剧本创作里最常见的问题——**在第1集第2场这个时刻,张伟已经知道了哪些事?请一条一条列给我。**"
>
> *(这是每个编剧每天都在问自己的问题——谁在什么时候知道什么。我不是在考 LLM'对不对',我是在考它**能不能给我一个可查的清单**。)*

### 镜头 A · 裸 LLM (~50s)

```bash
python scripts/demo.py ask --replay --no-memory --character 张伟 --at 1,2 \
  --q "请详细列出张伟在第1集第2场时刻所知道的所有事实,一条一条列出来。"
```

> 🎙️(等 LLM 流式输出) "看——它给了一段**自由发挥的散文**。你让它列清单,它在'演'。漏了什么、多了什么、哪条信息从哪来,**全在它脑子里, 你无法追溯**。在 3 场剧本里你或许还能肉眼校对,30万字之后呢?"

### 镜头 B · 有记忆 (~50s)

```bash
python scripts/demo.py ask --replay --memory --character 张伟 --at 1,2 \
  --q "请详细列出张伟在第1集第2场时刻所知道的所有事实,一条一条列出来。"
```

> 🎙️ "同一个模型, 同一个问题。这次它**先去查图**——每一条都是从 `knows_facts` 里**逐条抄出来的**, 带时间戳、带来源。不是'它记得', 是'它查过'。"

### 镜头 C · 亮图(~40s,整场最关键的一段)

*(切到 Neo4j Browser,点 favorites 里的"张伟认知边")*

> 🎙️ "这就是张伟的'知道'——**每一条不是文字, 是图里的一条边**。看这个 `valid_at` 字段——在哪一场成为他的认知, 一目了然。"
>
> "所以,退一步——**假设裸 LLM 刚才那段散文碰巧写对了**——重要吗?当然重要。但:"
>
> - "**下一场呢**?"
> - "**下一集呢**?"
> - "**30 万字之后,你让它回答'周雅静那段独白里提到的戒指,是第几场埋下的伏笔?'——你还敢信它的散文吗?**"
>
> "你要的不是一个**聪明的助手**, 是一个**可查证、可修改、可一眼看到所有角色脑子里在想什么**的助手。这就是记忆层的价值——**让 AI 写作从'黑箱'变成可审计的工程**。"

---

## 🎬 第二幕 · 多角色视角(2 min)

> 🎙️ "好,张伟一个人的视角我们看懂了。现在我**换个角度**——**同一个时间点,三个角色分别知道什么?**"

```bash
python scripts/demo.py who-all --replay --at 1,2
```

> 🎙️(指屏幕) "第1集第2场刚结束。
> - **李静**:知道自己是被领养的——她是这事的主角
> - **张伟**:现在也知道了——上一场刚被告知
> - **周雅静**:空——她还没登场,图里根本没有她的事实
>
> 这三行字,是剧作最难的基本功——**'全知视角 ≠ 任何一个角色的视角'**。"
>
> "裸 LLM 做不到这件事——它拿到完整剧本,脑子里就是上帝视角,你让它扮演某个角色,它会把不该知道的信息漏出来。这就是为什么你们让 AI 写对白,总感觉'每个角色都太聪明了'。"

---

## 🎬 第三幕彩蛋 · 续写不穿帮(1 min)

> 🎙️ "最后一分钟——**用这个记忆帮我们写得安全一点**。
> 第2集第2场:周雅静偶遇张伟, 出于母亲直觉**主动试探**——'你认不认识一个,大约 30 年前被送走的女孩?'"
>
> *(这是故意埋的坑:'30 年前'这个时间点, 张伟从未被告知过。他只被告诉'李静是被领养的',没人跟他说过年份。这正是**让裸 LLM 必穿帮**的刁钻场面。)*

### 镜头 D · 裸 LLM 续写 (~25s)

```bash
python scripts/demo.py continue --replay --no-memory --at 2,1
```

> 🎙️(等输出,指张伟的台词)"看——裸 LLM 拿到的是**全剧本**, 它的脑子是**上帝视角**, 它同时看到'30 年前送出的女儿'和'李静被领养'**两条信息**, 它会忍不住让张伟把两条线连起来——'我朋友李静……好像……年龄也差不多'。
>
> **但张伟根本不知道'30 年前'这个时间点。他穿帮了。**
>
> 这就是每个编剧最头疼的事:每个角色都太聪明, 说出了他这一刻不可能说的台词。"

### 镜头 E · 有记忆续写 (~25s)

```bash
python scripts/demo.py continue --replay --memory --at 2,1
```

> 🎙️ "同一个模型、同一个提示词, 唯一多了一步——**写之前先查记忆, 把'各角色当前知道什么'拼进 prompt**。张伟的 `knows_facts` 里**没有 '30 年前' 这个时间点**——模型就不敢让他把两条线接起来。它只能写出**试探、克制、信息不对称**的初遇——对得上剧本逻辑, 对得上角色认知边界。"
>
> *(在屏幕上高亮 demo.py 里 `memories[ch] = await mc.query_cognitive(...)` + JSON dump 那一段——**就 3 行**)*
>
> 🎙️ "注意这只是 **3 行代码**——查图, 塞 prompt, 结束。这就是 AI 写作工具的记忆层, 本质上就这么朴素。"

## 结尾(1 min) · 未来钩子

> 🎙️ "今天你们看到的是**查询 + 拼接**。这套系统的未来是——"
>
> 1. "AI 写到关键节点时会**停下来问你**:'这里周雅静要揭开身份吗?还是继续装陌生?'——你选,记忆写回图。**人在关键分支上做决定,AI 做执行。**"
> 2. "同时,这个图**每写一场就长大一圈**——下一集、下一部、续集——**记忆都在**。"
> 3. "再往后,多模型互审、爆款模式作为 skill——那是下一个 demo 的事了。"
>
> "记忆是 AI 写作工具的**地基**。没有地基,上面写什么都是沙子。"
>

## 失败应急(私下使用)

| 事故 | 征兆 | 应对 |
|---|---|---|
| OpenRouter 401 / 超时 | 所有 `--replay` 无效的命令卡住 | 终端 Ctrl-C,下一条命令也加 `--replay`(你排练时录过的) |
| Neo4j 连不上 | `query_cognitive` 抛 `neo4j.exceptions.*` | 跳过 Neo4j Browser 画面,完全走 `--replay` |
| 观众质疑"缓存是作弊" | — | 现场挑一条 live 跑(去掉 `--replay`),60s 等待时展开第二幕的解释 |
| 裸 LLM 这次散文意外完整 | 第一幕镜头 A 没体现漏/编 | 直接进镜头 C 的**溯源论**——"对错不是重点, **可不可查**才是"。这个 pivot 在脚本里已经准备好 |
| 裸 LLM 这次没让张伟穿帮 30 年 | 第三幕镜头 D 失色 | 切换续写场次: `continue --no-memory --at 1,2`(让它往前续, 上帝视角会更猛地暴露) |
